# Python Inputs & Data Type Conversion Assessment

**Topic Covered:** `input()`, `int()`, `float()`, `str()`, `type()`, and basic calculations.

Assign one section to each trainee. Each section contains **4 progressively harder exercises**.

---

# Muhammed

### Exercise 1

Ask the user to enter their name and print:

```
Hello, <name>
```

### Exercise 2

Ask the user to enter their age. Convert it to an integer and print:

```
You are <age> years old.
```

### Exercise 3

Ask the user to enter two numbers. Convert both to integers and print their sum.

### Exercise 4

Ask the user to enter their birth year. Calculate and print their approximate age.
