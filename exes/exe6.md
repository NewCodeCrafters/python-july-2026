# Beginner Function Exercises (No Function Name Hints)

## Muhammed

Write a function that prints **Welcome to Python Programming**.

## Emmanuel

Write a function that prints your full name on one line.

## Ore

Write a function that receives a person’s name and prints a greeting for that person.

## Ayomide

Write a function that receives a city name and prints **I live in *city***.

## Justice

Write a function that receives one number and prints its square.

## Destiny

Write a function that receives one number and prints its cube.

## Maleek

Write a function that receives two numbers and prints their sum.

## John

Write a function that receives two numbers and prints their product.

## John

Write a function that receives two numbers and prints the larger number.

## Maleek

Write a function that receives one number and prints **Even** if the number is even, otherwise print **Odd**.

## Destiny

Write a function that receives a student’s score and prints **Pass** if the score is 50 or above; otherwise print **Fail**.

## Justice

Write a function that receives the length and width of a rectangle and prints the area.

## Ayomide

Write a function that receives three numbers and prints their average.

## Ore

Write a function that receives one number and prints all numbers from 1 up to that number.

## Emmanuel

Write a function that receives one number and prints the multiplication table for that number from 1 to 10.

## Muhammed

Write a function that receives a word and prints the number of characters in that word.
